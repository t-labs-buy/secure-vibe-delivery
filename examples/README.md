# Config to copy into your project

Both files install secure-vibe-delivery v0.1.6 from the company repository. Commit them to a
project so everyone who opens it gets the server.

| Client | Copy | To |
|---|---|---|
| Claude Code | `claude-code/.mcp.json` | `<your project>/.mcp.json` |
| VS Code | `vscode/mcp.json` | `<your project>/.vscode/mcp.json` |

To move to a newer release, change `@v0.1.6` to the new tag.
